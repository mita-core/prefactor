§01 / THE GAPproblem: observe ≠ intervene

The gap

You evaluated 5%.
You shipped 100%.

That's the gap. Sampled scoring, unchecked judges and pre-release test suites tell you how your agents behaved in the lab. None of it tells you what your agents are doing right now, on live traffic, in front of real customers.

5% evaluated 95% live, unwatched
01◐

The 95% you didn't sample

The run that loses the account is one you never scored. You find out from the customer, not the dashboard.

02§

Who judges the judge?

One biased judge poisons every score downstream. You're making ship or kill calls on numbers nobody verified.

03✕

Static evals are not in prod

The run that breaks in front of a customer was never in your test set. Your suite passes while prod burns.

§09 / FAQreference: owned terms first

What you need to know

What is agent observability?

Capturing every agent run as structured trace data (each LLM call, tool invocation and decision) so you can see exactly what an agent did, how well it performed, and what it cost.

What is agent evaluation?

Continuously scoring agent outputs with the evals you define (LLM-as-judge, technical checks and qualitative metrics) on real production traffic, so you catch drift and regressions before your users do.

How do I instrument my agent with Prefactor?

Install the CLI (prefactor init) and add the TypeScript or Python SDK, native for LangChain, Claude, Vercel AI, OpenClaw and LiveKit. For coding and workflow tools, send OpenTelemetry spans, or instrument anything else with the core SDK. Minutes, no platform migration.

What are custom spans, and how do they measure quality?

A custom span marks a step that matters: a retrieval, a tool call, a sub-agent. You layer them in to run your own evals on it (LLM-as-judge, technical and qualitative metrics) and watch scores trend over time, with P95/P99 latency alongside, not just the final answer.

How does human-in-the-loop work?

High-risk actions can be paused and routed to a person to approve, modify or reject before they execute, via the SDK or the API, which enforces the decision at runtime. Every decision is logged.

How does Prefactor enforce at runtime?

Through the SDK or API, Prefactor can pause a run and hold a high-risk action for human approval before it executes. Sensitive-data detection and risk classification drive what gets held.

Why do AI agents need identity and scoped access?

So each action ties to a specific agent, task and user context, enabling least privilege, traceability and revocation.
